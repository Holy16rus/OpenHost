# OpenHost — Текущий статус

## Что сделано

### Каркас бота (Holy16rus)

- `main.py` — запуск aiogram 3.26, polling
- `handlers.py` — хэндлеры `/start`, "Информация", "Настройки"
- `keyboards.py` — главная клавиатура + инлайн
- `Docker/` — Dockerfile и скрипты для сборки Heroku в контейнере

### Хэндлер установки (Samuray4ik04)

- Кнопка "Установить юзербота" — объясняет что произойдёт, спрашивает подтверждение
- `docker_manager.py` — создание/остановка контейнеров, SSH-туннель (serveo.net / localhost.run)
- Изоляция контейнеров по user_id (`openhost-{user_id}`)
- Ограничение доступа по списку `ALLOWED_USERS`
- Обработка ошибок если Docker недоступен
- Обновлено под Heroku 2.0.0 (Python 3.14, новые зависимости, xfonts)

## Что обсуждали

### Способ установки юзербота

- **Docker** — надёжно, изолированно, переживает ребут, но требует Docker на сервере
- **systemd** — проще, работает везде, venv + systemd unit на каждого юзербота, менее изолировано
- **Оба варианта** — дать юзеру выбор при установке
- Пока не решили какой путь выбрать

### Туннели для веб-авторизации

- serveo.net как основной, localhost.run как fallback
- В РФ ngrok не работает
- Heroku использует тот же подход (SSH -R)

### Автоустановка Docker

- В `docker.sh` уже есть скрипт установки Docker (Debian/Arch/RHEL)
- Опасно запускать из бота (sudo, apt-get) — лучше проверять и кидать инструкцию
