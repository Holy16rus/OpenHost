# OpenHost
Host for Telegram Userbots

## Быстрый старт

Скопируйте и вставьте в терминал:

```bash
sudo apt update && sudo apt upgrade -y && sudo apt install git python3-pip -y && git clone https://github.com/Holy16rus/OpenHost && cd OpenHost && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && python3 main.py
```

При первом запуске бот попросит ввести BotToken — создайте бота через [@BotFather](https://t.me/BotFather) и вставьте токен.
